# Ícone da app

- `icon.svg` — fonte (recibo com €, fundo em gradiente teal).
- Android: ícone adaptativo em vetor (`composeApp/src/androidMain/res/drawable/ic_launcher_*.xml` + `mipmap-anydpi-v26`), suporta ícones temáticos (monochrome).
- `icon-1024.png` — App Store / AppIcon do iOS (no projeto Xcode `iosApp`: Assets.xcassets → AppIcon → 1024×1024).
- `icon-512.png` — Google Play (ícone da ficha).
- `icon-180.png` — apple-touch-icon da web.
